# APEX Fitness storefront

A responsive, single-page storefront prototype for a fictional sports nutrition brand. The project was created for a hackathon and is built as a standalone HTML file with embedded CSS and JavaScript.

## Preview

Open [`hackathon/prsent.html`](hackathon/prsent.html) in a browser.

## What it demonstrates

- A responsive landing page and product catalog
- Product cards with add-to-cart and quantity controls
- A cart summary shown with a browser dialog

## Run locally

No build tools are required. Clone or download the repository, then open `hackathon/prsent.html`. Some images load from Unsplash, so an internet connection is needed to see every image.

## Prototype notes

This is a front-end demo. The cart is held in memory and resets when the page reloads; there is no backend, saved cart, or checkout. The product details, prices, statistics, nutrition copy, and contact information are sample content for the mock storefront, not real offers or claims.
